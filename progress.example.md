# Drill Progress (template)

Copy this file to `progress.md`. The coach reads and appends to `progress.md`, not
this file. Leave it mostly empty at the start — the coach fills it in after each
session.

## Recall Queue (spaced repetition)
Resurfaces EVERY drilled row, including clean first-try passes — not just misses. A
row you nailed cold decays too, just slower, so it still needs to come back around.
Box schedule: Box 1 → due next session · Box 2 (1 clean recall) → due ~2 sessions
later · Box 3 (2 clean recalls in a row) → due ~4 sessions later · Box 4 (3 in a row)
→ retired, drop the row. A miss at any box drops it back to Box 1.

Every session's warm-up pulls the 1-2 rows with the oldest "Due" session, before any
new drilling. At session end, log or update every row actually drilled — pass or miss.
